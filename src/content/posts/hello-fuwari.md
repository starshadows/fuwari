这是这个博客的第一篇文章。

现在它还很简单，但已经具备一个个人博客最重要的能力：

- 可以在本地预览
- 可以用 Markdown 写文章
- 可以提交到 GitHub
- 可以通过 Cloudflare Pages 自动发布

以后我会把学到的东西、踩过的坑、项目记录和一些生活想法慢慢写在这里。
